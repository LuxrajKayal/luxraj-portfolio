### ✨ What makes it useful?

Anatomy is an AI-agent skill and drawing toolkit that helps turn abstract concepts into physical, interactive illustrations. Instead of presenting only text or static diagrams, it can construct detailed objects with component-level geometry, animation, live readouts, and visual effects.

**Core capabilities**
- **Isometric SVG illustrations** — detailed objects with depth, shading, and component-level construction.
- **Interactive animations** — show how mechanisms and components behave.
- **SVG + WebGL** — add effects such as flames, water, light, and other visual phenomena.
- **Experimental 3D mode** — animate selected parts in three-dimensional space.
- **Multiple output formats** — standalone HTML, SVG, and React components.

### 🛠️ Installation

The project documents installation through the Skills CLI:

```bash
npx skills add wheresryan22/anatomy -g
```

After installation, invoke the skill through a compatible AI coding agent. For example, in Codex:

```text
$anatomy explain how a PDF annotation layer works, interactive
```

Review the installation instructions and your agent's current skill compatibility before setup.
